Conectar (una sola vez)

  1. Entra a GitHub → crear token.
  2. En Repository access elige Only select repositories y marca solo el repositorio de la página.
  3. En Permissions → Repository permissions pon Contents: Read and write. Nada más.
  4. Toca Generate token, copia el que empieza con github_pat_ y pégalo abajo.
